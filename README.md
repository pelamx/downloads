# bubbleTranslate — downloads

The downloads for [bubbleTranslate](https://bubbletranslate.app), and
`latest.json`, which is what installed copies read to learn that a newer
version exists.

| System | Download |
|---|---|
| macOS | [`bubbleTranslate.dmg`](https://github.com/pelamx/downloads/releases/latest/download/bubbleTranslate.dmg) |
| Windows | [`bubbleTranslate-windows-x64.zip`](https://github.com/pelamx/downloads/releases/latest/download/bubbleTranslate-windows-x64.zip) |
| Linux | [`bubbleTranslate-linux-x86_64`](https://github.com/pelamx/downloads/releases/latest/download/bubbleTranslate-linux-x86_64) |

`SHA256SUMS.txt` is published beside them on every release.

What each version changed is written on the release it belongs to.
